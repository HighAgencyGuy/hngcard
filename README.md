# Ferguson Profile Card

A responsive profile card web component for Ferguson Aya, built with HTML, CSS and JavaScript.

## Features

- Modern, accessible design
- Responsive layout for desktop and mobile
- Dynamic display of current time (ms)
- Social links and hobbies/dislikes sections
